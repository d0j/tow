      Transmission http://nas.example:9091/transmission · 1 topic
      How to connect
      1. In Transmission: Edit → Preferences → Remote.
      2. Turn on “Allow remote access”; the port is usually 9091. User name and password are optional.
      3. If Transmission runs on another computer, add this computer's address to the allowed list.

      Transmission 3.0 or newer is needed: TOW marks its torrents with the label tow. Magnet links are not supported with Transmission — it starts downloading before TOW can choose the files.

      How to connect
      1. In Discord, open the channel → ⚙ “Edit Channel” → “Integrations” → “Webhooks”.
      2. Press “New Webhook”; you may name it TOW.
      3. Press “Copy Webhook URL”.

      The webhook is a key to the channel; TOW keeps it encrypted.

      If access is still blocked

      Expand the topic's warning for each mirror's reason and retry time. The log identifies the failed stage: module startup, service response or topic access. A connection failure needs its type and address checked; a sign-in error needs the account checked on Sites.

      Services do not remove bans, download quotas or request rate limits. Wait out a 429 pause. An interactive check may require supported browser sign-in; access through every future challenge is not guaranteed.
