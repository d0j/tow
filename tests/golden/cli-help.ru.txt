$ tow --help
использование: tow [-h] <command> ...

TOW следит за раздачами на торрент-сайтах и передаёт новые версии в ваш торрент-клиент.

аргументы:
  <command>
    version           показать версию TOW
    status            одна строка о TOW: запущен ли, торрент-клиент, сайты, раздачи, последняя и
                      следующая проверка, автозапуск
    doctor            опросить торрент-клиент и сайты сейчас и показать, кто отвечает
    permissions       кто может войти в папки TOW; fix закрывает их
    adopt             взять под управление раздачи, чей торрент есть в клиенте без метки tow: TOW
                      ставит метку (больше ничего не меняет) и дальше управляет им
    check             проверить раздачи сейчас (без --apply — предпросмотр, ничего не меняется)
    access            доступ по сети с других устройств: включить, выключить или посмотреть
    secrets           зашифрованное хранилище паролей и токенов
    keys              мастер-ключ внутри установки (keys/master.key)
    export            сохранить настройки, раздачи, историю, пароли и токены в один файл,
                      защищённый парольной фразой (для другой установки, даже с другим мастер-
                      ключом)
    import            восстановить из файла `tow export` (без --apply только просмотр)
    import-rollback   вернуть то, что заменил импорт, из его контрольной точки
    backup            сделать ночную копию сейчас (в backup_dir)
    restore-snapshot  восстановить данные из ночной копии
    watchdog          один обход сторожа сейчас, как tow run делает каждые 10 минут: работает ли
                      TOW и идут ли проверки? Его сообщения тоже уходят в мессенджеры; он ничего
                      не перезапускает
    password          задать новый пароль TOW и подсказку (старый не нужен)
    run               запустить TOW единым сервисом: веб-страница, расписание, ночные копии и
                      сторож
    start             запустить TOW в фоне (если он ещё не работает) и открыть его страницу в
                      браузере
    stop              остановить запущенный `tow run` (он даёт закончиться идущей проверке)
    restart           перезапустить веб-сервер запущенного `tow run`
    setup             пересобрать окружение: команда запускающего скрипта, а не этого окружения
    autostart         запускать TOW вместе с компьютером (Планировщик заданий, systemd, launchd)
    update            как обновить эту установку до выпуска

параметры:
  -h, --help          показать эту справку и выйти

коды завершения (у всех команд):
  0    выполнено
  1    неверная команда или параметр
  2    выполнено частично: не удалась раздача, зеркало или шаг
  3    невозможно выполнить: нет или повреждены настройки, пароли и токены, блокировка или файл
  130  прервано (Ctrl+C)

«setup» — команда запускающего скрипта (scripts\tow.cmd setup): она пересобирает окружение после
переноса или обновления, когда TOW остановлен.
Каждая команда объясняет себя: tow КОМАНДА --help

$ tow permissions --help
использование: tow permissions [-h] [--owner ACCOUNT] [--json] [{status,fix}]

Показывает, могут ли другие учётные записи этого компьютера войти в папку TOW, папку ключа и папку
данных, и кому они принадлежат. «fix» закрывает их; папку другой учётной записи (созданную в
терминале администратора) он передаёт владельцу, если запустить его в терминале, открытом через
«Запуск от имени администратора» (Linux, macOS: через sudo): учётной записи из --owner, иначе той,
которой уже принадлежит папка TOW, иначе той, под которой работает автозапуск TOW, иначе той, что
открыла терминал. Ничего вне папки TOW не меняется.

аргументы:
  {status,fix}     status (по умолчанию) или fix

параметры:
  -h, --help       показать эту справку и выйти
  --owner ACCOUNT  для fix: учётная запись, которой передать папки (КОМПЬЮТЕР\имя или имя), если
                   TOW не может определить, чья это установка
  --json           вывод для программ (JSON), в том числе при ошибке

$ tow restore-snapshot --help
использование: tow restore-snapshot [-h] --path PATH [--apply] [--json]

Восстанавливает данные из ночной копии (её папка в backup_dir), в том числе пока TOW работает. Без
--apply только проверяет копию (для этого нужен мастер-ключ этой установки) и показывает, что
изменится. С --apply сначала сохраняет текущие данные в data/before-restore-* и сам возвращает их,
если что-то не удалось. Доступ по сети не меняется, а История сохраняет всё, что было после копии.

параметры:
  -h, --help   показать эту справку и выйти
  --path PATH  папка ночной копии
  --apply      восстановить (без него только проверка и просмотр)
  --json       вывод для программ (JSON), в том числе при ошибке

$ tow update --help
использование: tow update [-h] --ref REF

Обновление заменяет это самое окружение, поэтому выполняется не отсюда: команда показывает, чем
его запустить (базовый Python установки с app/scripts/update.py, deploy.ps1 в клоне git в Windows
или файл обновления в папке TOW для установки без git). Обновление останавливает TOW, сохраняет
снимок data/ и config.yaml, ставит выпуск, запускает TOW и само возвращает прежнюю версию, если
что-то не так.

параметры:
  -h, --help  показать эту справку и выйти
  --ref REF   метка выпуска, например v1.22.0; установка без git принимает и latest
