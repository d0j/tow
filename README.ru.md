# TOW

**Наблюдатель за раздачами:** следит за темами на форумных трекерах, где торрент заменяют в той же теме, и
передаёт каждую новую версию вашему торрент-клиенту.

[![CI](https://github.com/d0j/tow/actions/workflows/ci.yml/badge.svg)](https://github.com/d0j/tow/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python 3.14](https://img.shields.io/badge/python-3.14-blue.svg)](.python-version)

[English version](README.md)

На многих трекерах у сериала одна тема, и с каждой новой серией в ней меняют `.torrent`. TOW проверяет такие темы
по расписанию, замечает новую версию, добавляет её в qBittorrent, Transmission или Deluge ровно с теми файлами,
которые вы выбрали, убеждается по ответу клиента, что всё добавилось, и пишет вам в Telegram, Discord, WhatsApp
или ntfy.

Веб-страница — это один список: строка на раздачу, точка состояния, сайт, папка, последнее событие и прогресс.

## Кому подойдёт

- Вы смотрите сериалы с rutor, Kinozal, RuTracker или NNM-Club, где тема обновляется на месте.
- На домашнем компьютере или небольшом сервере работает торрент-клиент с веб-интерфейсом.
- Хочется, чтобы новые серии добавлялись сами, каждый раз в ту же папку и с тем же выбором файлов.

**Чем TOW не является:**

- это не качалка — сам TOW ничего не скачивает, качает ваш клиент;
- это не поиск и не RSS — ссылки на темы даёте вы;
- это не обход правил сайтов — ни капчи, ни Cloudflare, ни чужих аккаунтов.

## Возможности

- Наблюдать за темой или добавить один раз. Все файлы, серии (`S01E03-E05`, `04x01-03`) или маски (`*.mkv`).
- Каждое добавление — транзакция: раздача добавляется остановленной, выбираются файлы, выбор читается обратно, и
  только потом она запускается. Сбой называется сбоем, а не успехом.
- Несколько зеркал у сайта: если одно молчит, берётся следующее, упрямое зеркало отдыхает час. Дневной лимит
  скачиваний соблюдается.
- Вход на сайт по паролю или, где сайт этого требует, через окно браузера.
- Одно сообщение на проверку, тихие часы, ежедневная сводка, очередь доставки переживает перезапуск.
- Цвета различают «сайт временно недоступен» (жёлтый) и «нужно ваше участие» (красный).
- История каждого файла и версии; отмена последнего изменения одной кнопкой.
- Ночные копии, точки восстановления перед рискованными действиями, зашифрованные файлы переноса (`.towx`).
- Всё в одной папке: код, настройки, данные, ключ, копии и свой Python. Папку можно перенести — TOW продолжит работать.
- Интерфейс на русском и английском; новый язык — один JSON-файл.
- Импорт из Monitorrent.

## Что поддерживается

| Что | Поддержка |
|---|---|
| Сайты (готовые настройки) | rutor, Kinozal, NNM-Club, RuTracker, Tapochek, UnionPeer, fast-torrent; похожий сайт настраивается вручную |
| Торрент-клиенты | qBittorrent (веб-интерфейс), Transmission 3.0+, Deluge 2.x |
| Уведомления | Telegram, Discord, WhatsApp (через CallMeBot), ntfy |
| Системы | Windows 10/11; Linux и macOS — экспериментально, пока CI на них не зелёный |
| Что нужно | git и [uv](https://docs.astral.sh/uv/) ≥ 0.12; Python 3.14 `setup` ставит сам, внутрь папки TOW |

## Быстрый старт

Нужны [git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/getting-started/installation/). TOW живёт в одной
папке (ниже — `~/TOW`), код лежит в её подпапке `app`.

**Windows** (PowerShell):

```powershell
git clone --branch v1.21.0 https://github.com/d0j/tow "$HOME\TOW\app"
cd "$HOME\TOW\app"
Copy-Item config.example.yaml ..\config.yaml
.\scripts\tow.cmd setup
.\scripts\tow.cmd run
```

**Linux / macOS** (экспериментально):

```sh
git clone --branch v1.21.0 https://github.com/d0j/tow ~/TOW/app
cd ~/TOW/app
cp config.example.yaml ../config.yaml
./scripts/tow setup
./scripts/tow run
```

Откройте <http://127.0.0.1:8787>. `setup` ставит Python и зависимости в `TOW/runtime`, а при первом запуске TOW
создаёт мастер-ключ `TOW/keys/master.key` и один раз напоминает сохранить его копию.

> [!IMPORTANT]
> **Сразу сохраните копию `keys/master.key`** — на флешку или в менеджер паролей. Им зашифрованы все сохранённые
> пароли и токены. В ночные копии и файлы `.towx` он не попадает, и без него их не восстановить.

## Первые пять минут

1. **Страница «Добро пожаловать».** Задайте пароль для других устройств или пропустите шаг: на этом компьютере TOW
   открывается без пароля.
2. **Настройки → Торрент-клиенты.** Включите веб-интерфейс в клиенте, введите адрес, порт, логин и пароль, нажмите
   **Проверить**.
3. **Настройки → Уведомления** (по желанию). Пройдите «Как подключить» у мессенджера и нажмите **Проверить**.
4. **Главная → +.** Вставьте ссылку на тему, при желании поправьте название и папку, выберите, что качать и
   следить ли дальше, нажмите **Добавить**.
5. **Смотрите на точку.** Зелёная — добавлено и подтверждено. Синяя — найдено новое. Жёлтая — сайт пока недоступен.
   Красная — откройте строку, причина там.

Каждый экран, цвет и сообщение разобраны в [руководстве](docs/ru/guide.md).

## Постоянная работа

```sh
tow autostart on       # запуск вместе с компьютером: Планировщик (Windows), systemd (Linux), LaunchAgent (macOS)
tow autostart status
tow autostart off
```

Здесь и дальше `tow` — это лаунчер: `.\scripts\tow.cmd` в Windows и `./scripts/tow` в Linux и macOS, из папки
`TOW/app`. Автозапуск — единственное, что TOW пишет вне своей папки, и только по вашей команде. С
`--without-login` TOW стартует при включении компьютера, ещё до входа в систему. Остановить и перезапустить:
`tow stop`, `tow restart`.

## Сервер без монитора

TOW слушает только `127.0.0.1:8787`. Чтобы открыть его с другой машины, выберите один способ:

| Способ | Как | Пароль |
|---|---|---|
| SSH-туннель | `ssh -L 8787:127.0.0.1:8787 user@server`, затем <http://127.0.0.1:8787> | не спрашивается: туннель приходит как локальный |
| Домашняя сеть или VPN | `tow access on` (спросит пароль, если он не задан), затем `tow restart`; адрес `http://<сервер>:8787` | всегда |

Запросы с публичных адресов интернета TOW отклоняет, поэтому проброс порта на роутере не сработает — используйте VPN
(WireGuard, Tailscale) или туннель. `tow access off` снова закрывает сеть, `tow access status` показывает,
что задано.

> [!WARNING]
> **Обратный прокси.** Прокси на той же машине передаёт все запросы с `127.0.0.1`, и TOW считает их локальными —
> без пароля. Не ставьте TOW за прокси; если без него никак, прокси должен сам проверять каждого пользователя.

## Командная строка

`tow --help` перечисляет все команды; `tow <команда> --help` объясняет их параметры.

```sh
tow status            # одна строка: запущен ли, торрент-клиент, сайты, раздачи, последняя и следующая проверка, автозапуск
tow doctor            # опросить торрент-клиент и сайты сейчас
tow check --apply     # проверить все раздачи сейчас
tow keys ensure       # создать keys/master.key в новой установке (tow run делает это при первом запуске)
```

| Код завершения | Значение |
|---|---|
| 0 | выполнено |
| 1 | неверная команда или параметр |
| 2 | выполнено частично: не удалась раздача, зеркало или шаг |
| 3 | невозможно выполнить: нет или повреждены настройки, секреты, блокировка или файл |
| 130 | прервано |

С `--json` команда выводит JSON, в том числе при ошибке.

## Копии и мастер-ключ

| Что | Где | Есть ли в нём ключ |
|---|---|---|
| Ночная копия (03:30, последние 14) | `TOW/backup/night/` | нет |
| Точка восстановления (Настройки → Резервные копии, последние 10) | `TOW/data/restore-points/` | нет |
| Файл TOW `.towx` (Настройки → Резервные копии) | куда сохраните | нет — для восстановления нужен тот же `master.key` |
| Снимок перед обновлением (последние 5) | `TOW/backup/update-…` | нет |
| **Мастер-ключ** | `TOW/keys/master.key` | **это и есть ключ** — храните копию вне компьютера |

Чтобы переехать на другой компьютер, скопируйте папку `TOW` целиком (вместе с `keys/`) и выполните там `tow setup`.
Чтобы перенести только данные между установками с разными ключами, используйте `tow export` и `tow import` — они
спрашивают свою парольную фразу. Потерянный ключ не воссоздать: если TOW сообщает, что ключа нет, верните сохранённую копию командой
`tow keys adopt --from ФАЙЛ`.

## Обновление и откат

```powershell
.\scripts\deploy.ps1 -Ref v1.21.1       # Windows, PowerShell 7
```

В любой системе `tow update --ref v1.21.1` печатает точную команду для этой установки. Обновление останавливает TOW,
сохраняет снимок `data/` и `config.yaml`, переключает код, пересобирает окружение, запускает TOW и проверяет, что
отвечает новая версия. Если что-то не так, код и данные возвращаются по шагам (журналы неудачной версии
сохраняются). Вернуться позже — обновиться на предыдущий тег, но не старше v1.18.0. Подробности — в
[docs/PORTABLE.md](docs/PORTABLE.md) (на английском).

`<python>` — базовый Python установки (его называет команда, которую печатает `tow update`):

| Что | Windows | Linux / macOS |
|---|---|---|
| Обновить | `.\scripts\deploy.ps1 -Ref v1.21.1` | `<python> scripts/update.py --ref v1.21.1` |
| Вернуться на прежнюю версию (не старше v1.18.0) | `.\scripts\deploy.ps1 -Ref v1.20.0` | `<python> scripts/update.py --ref v1.20.0` |
| Восстановить ночную копию | `tow restore-snapshot --path <копия>` — проверка, затем то же с `--apply` | так же |
| Вернуть снимок перед обновлением вручную | `tow stop`, затем скопировать `<снимок>\data\*` поверх `TOW\data\` и `<снимок>\config.yaml` поверх `TOW\config.yaml` | `tow stop`; `cp -a <снимок>/data/. TOW/data/`; `cp <снимок>/config.yaml TOW/` |
| Python и окружение (после переноса или новой копии) | `tow stop`, `tow setup` | `tow stop`, `tow setup` |

Чтобы перенести установку в другую папку или на другой диск: `tow autostart off`, `tow stop`, перенести папку `TOW`
целиком, выполнить `tow setup` на новом месте и `tow autostart on`. (Автозапуск, который указывает на уже
несуществующую папку, `tow autostart on` заменяет сам.)

## Переезд с Monitorrent

```sh
tow import-monitorrent --db путь/к/monitorrent.db           # предпросмотр: что будет импортировано
tow import-monitorrent --db путь/к/monitorrent.db --apply   # импорт тем и логинов
```

Перед импортом создаётся точка восстановления. Повторы (тот же номер или ссылка) пропускаются, логины заполняют
только пустые места.

## Правовая оговорка

TOW не связан ни с одним трекером, торрент-клиентом или мессенджером. Он не размещает, не индексирует и не скачивает
контент: читает страницы, на которые вы его направили, и передаёт торрент-файлы вашему клиенту. Соблюдать правила
сайтов и законы своей страны — ваша ответственность.
