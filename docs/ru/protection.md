# Доступ к сайтам

Обычные HTTP-запросы, настроенные зеркала и вход на сайт работают без внешнего сервиса. Необязательный слой доступа
выключен, если `protection` отсутствует. Он не устанавливает браузер, не меняет системный прокси и не скачивает видео.

## Подключение необязательного сервиса

1. Отдельно запустите доверенный [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr),
   [Byparr](https://github.com/ThePhaseless/Byparr), [FlareBypasser](https://github.com/yoori/flare-bypasser) или
   [Trawl](https://github.com/germondai/trawl). Не открывайте API в интернет; ограничьте браузеру доступ к LAN,
   link-local и служебным адресам облака. Этот браузер находится вне сетевой изоляции TOW.
2. На компьютере TOW откройте локальный адрес → Настройки → Доступ к сайтам → Добавить подключение. Выберите тип,
   укажите loopback/IP частной сети и порядок. Допускается только путь `/v1`; localhost превращается в 127.0.0.1.
3. Включите подключение и общий выключатель, затем сохраните. Сохранение не обращается к сервису и не подтверждает
   его работу: API проверяется только тогда, когда applying-проверке действительно нужен этот способ. Ответ API не
   доказывает доступ к сайту; его наблюдённое состояние и пауза сервиса показываются отдельно.

Можно сохранить несколько подключений одного вида. Меньшие номера идут первыми. Отсутствующий модуль, выключенное
подключение, отказ или неудачная попытка не мешают рассмотреть следующее включённое подключение в пределах общего
числа попыток и времени. Успешное прохождение любой защиты не гарантируется.
Если лимит попыток исчерпан без подтверждённого доступа, следующая допустимая проверка продолжит после последнего
использованного подключения: дальние подключения не остаются недостижимыми. Изменение настроек начинает порядок
заново, но не отменяет интервал. Отсутствующие модули и сервисы на паузе API не занимают место попытки.

Для совместимого `/v1`, в том числе отдельно работающего nodriver-форка, выбирайте FlareSolverr; библиотека nodriver
сама по себе не является HTTP-сервисом. FlareBypasser использует `request.get_cookies`, Trawl — `request.get` с
`returnOnlyCookies`. Протоколы проверяются по исходному коду, а не угадываются по названию браузера. TOW не импортирует
и не включает nodriver, zendriver или Camoufox. Фиксируйте и проверяйте версию внешнего сервиса и его зависимостей;
совместимый ответ не доказывает прохождение защиты.

На странице Сайты → дополнительные настройки сайта **Автоматически** разрешает необязательный слой; **Выключено**
запрещает его для этого сайта. **Вход через браузер** выбирает существующий явный вход владельца: внешние сервисы
не подменяют User-Agent этой сессии. Это не скрытый автоматический браузер.

## Порядок проверки

1. Обычные зеркала, с ранее подтверждённым доступом для точного origin, пока он действителен.
2. Только после отказа обычных зеркал с распознанной проверкой Cloudflare — включённые сервисы по порядку.
3. Сервис получает только публичную главную страницу: не пароль, данные аккаунта, тему, passkey или download.
4. TOW проверяет ограниченный ответ и самостоятельно обращается к главной странице с полученными данными доступа
   и соответствующим User-Agent.
5. Нужный ресурс запрашивается обычным защищённым HTTP TOW; при необходимости выполняется обычный вход на сайт.

Заголовок [`cf-mitigated: challenge`](https://developers.cloudflare.com/cloudflare-challenges/challenge-types/challenge-pages/detect-response/)
однозначно указывает на проверку. Известное название страницы со статусом проверки — запасной признак; обычный
прокси Cloudflare, скрипт или цитата на форуме не являются проверкой. Запрет доступа, ограничение частоты, сбой
сервера, техработы, квота и вход — разные причины, а не повод запускать сервис. Предпросмотр и диагностика его
никогда не вызывают. Перенаправление скачивания к другому origin использует новый клиент без данных входа;
домен cookie из ответа сервиса не разрешает передачу учётных данных другому origin.

Зашифрованный `data/protection.enc` хранит подтверждённый доступ, User-Agent, срок и предварительные записи попыток.
По умолчанию: 30 секунд на цепочку восстановления, до 2 доступных сервисов, 1800 секунд до новой попытки. Запись
попытки появляется до сетевого запроса, поэтому краш не вызывает запрос каждую секунду. Изменение настроек делает
старый доступ недействительным, но не отменяет паузу. Выключение запрещает его использование в последующих запросах;
уже отправленный запрос отозвать нельзя.

Ошибка соединения и ответы API о занятости/неверном протоколе приостанавливают только этот сервис для всех сайтов:
экспоненциальная пауза начинается с 30 секунд и ограничена 1800; корректный `Retry-After` может увеличить её до суток.
Отказ сайта при повторном запросе, медленная проверка и HTTP 500 не отключают сервис глобально. Переименование или
перестановка подключения не снимает паузу. У записи попытки собственный идентификатор: ответ до сброса или новой
попытки не вернёт старые cookies, не удалит новые и не восстановит старую паузу сервиса. Зашифрованный формат v2
читает v1 без перезаписи при просмотре; обновление происходит при новой записи только этого необязательного кеша.
Ошибки старше суток не увеличивают паузу при первом сбое нового дня. Сервису не отдаётся весь бюджет: до 10 секунд
(треть при меньшем бюджете) остаётся на независимую проверку. Временный сбой связи с главной или ошибка сервера
сохраняет проверенный доступ и не служит причиной новой попытки сервиса.

Если хранилище не читается, обычный HTTP остаётся доступным, а файл не заменяется молча. На компьютере TOW:
Настройки → Доступ к сайтам → Восстановление → **Сбросить сохранённый доступ**. Старые зашифрованные байты переходят
во временную папку TOW до обычной очистки. Пароли сайтов и настройки сервисов остаются; во время applying-проверки
сброс запрещён. Эта же операция сбрасывает сохранённые паузы сервисов.

## Текущая версия без повторного скачивания

Сайт может иметь `infohash_path` с `{id}`. Для Kinozal preset указывает страницу служебной информации. Принимается
только один явно подписанный текущий инфохеш. Если он совпадает с сохранённой версией, клиент должен независимо
подтвердить принадлежащую TOW задачу, папку и проверенный выбор, прежде чем TOW пропустит скачивание `.torrent`.
Проверка прогресса выполняется. Неизвестный формат или отсутствующая необязательная страница допускают обычное
скачивание; ошибка связи с сайтом сообщается без повторения тех же неудачных запросов. Новое правило, отсутствующая,
чужая или незавершённая задача и новый хеш проходят полный подтверждаемый клиентом путь. Это не обход квоты и не
доказательство актуальности из старого кешированного торрента.

## Ограничения

- `status: ok` сервиса не доказывает успех; доступ подтверждает отдельный запрос TOW.
- Работа только с главной страницей не решает проверку, включённую лишь для download. Внешний сервис может пробовать
  интерактивную проверку, но TOW не гарантирует её завершение; участие владельца может остаться необходимым.
  Отличающийся IP или отпечаток браузера/TLS может привести к безопасному отказу.
- Cloudflare [Precursor](https://developers.cloudflare.com/cloudflare-challenges/precursor/) может перепроверять
  продолжающийся сеанс и отменять clearance. Работа главной не доказывает доступ к другим страницам или пригодность
  cookies для отдельного HTTP-клиента. TOW проверяет нужный ресурс и записывает отказ повторного запроса; ответ API
  не выдаётся за восстановленный доступ к сайту.
- Сетевые операции и обработка ответа ограничены, но синхронный DNS операционной системы прервать нельзя. Поздний
  ответ не используется; зависший системный resolver может превысить номинальное время.
- HTTP сайта запрашивает только gzip, deflate и identity. Размер сжатых данных, каждого слоя распаковки и результата
  ограничен; повреждённое, незавершённое или неподдерживаемое кодирование отклоняется.
  Пустые ответы, включая перенаправления и HEAD, поддерживаются. Непустой сжатый поток с ошибкой CRC, обрывом или
  лишними данными намеренно отклоняется, даже если более терпимый клиент его принимает.
- Неправильный файл настроек остаётся ошибкой конфигурации. Недоступный настроенный сервис не запрещает обычную
  работу с сайтами. Импортируемое расширение — доверенный код, а не изолированная песочница.
- Последний ответ зеркала не доказывает работу всех его адресов: главная может работать, а скачивание — нет.
  Смотрите фактическую ошибку раздачи.
